# 🔐 Nicholas' Secure Password Generator

A clean, responsive, and customizable password generator built with HTML, CSS, and JavaScript — hosted with GitHub Pages.

## 🚀 Live Demo
Try it here 👉 [nicholaseb0.github.io/nicholas-password-generator](https://nicholaseb0.github.io/nicholas-password-generator/)

## ✨ Features
- Adjustable password length 
- Choose which characters to include:
  - ✅ Uppercase
  - ✅ Lowercase
  - ✅ Numbers
  - ✅ Symbols
- 🔑 Optional keyword injection (inserted at random position)
- 📋 Copy to clipboard
- 🌐 Mobile-friendly and accessible

## 📁 Tech Stack
- HTML5
- CSS3 (with custom styling)
- JavaScript (Vanilla)

## 🧠 How It Works
This generator allows users to customize every part of their password. Based on selected options, it randomly builds a secure password using a character pool. Keywords are randomly injected and the final result is shuffled for better randomness.
